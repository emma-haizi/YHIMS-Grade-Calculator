성적 계산기

제작 : YHIMS 16기 김아윤, 숭곡중학교 김유찬

기능 1 목표 등급 커트라인 계산

수행평가(또는 중간고사) 점수를 입력하면 목표 등급 달성에 필요한 최소 기말고사(또는 수행평가) 점수를 계산합니다.

기능 2 최종 성적 계산

지필고사와 수행평가 점수를 조합하여 최종 원점수를 계산합니다.

모드 직접 입력 / 2026학년도 3학년 프리셋

직접 입력 모드에서는 지필고사·수행평가 비율과 목표 등급(A~D)을 원하는 대로 설정할 수 있습니다. 한쪽 비율만 입력하면 나머지는 자동으로 채워집니다. 2026학년도 3학년 프리셋은 해당 학년도 기준 과목별 비율이 적용됩니다.
