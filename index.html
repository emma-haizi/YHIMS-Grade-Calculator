성적 계산기

제작 : YHIMS 16기 김아윤, 숭곡중학교 김유찬

기능 1 목표 등급 커트라인 계산

수행평가(또는 중간고사) 점수를 입력하면 목표 등급 달성에 필요한 최소 기말고사(또는 수행평가) 점수를 계산합니다.

기능 2 최종 성적 계산

지필고사와 수행평가 점수를 조합하여 최종 원점수를 계산합니다.

모드 직접 입력 / 2026학년도 3학년 프리셋

직접 입력 모드에서는 지필고사·수행평가 비율과 목표 등급(A~D)을 원하는 대로 설정할 수 있습니다. 한쪽 비율만 입력하면 나머지는 자동으로 채워집니다. 2026학년도 3학년 프리셋은 해당 학년도 기준 과목별 비율이 적용됩니다.

숭곡중 성적 계산기

제작 : 숭곡중학교 김유찬

기본성적 계산기가 뭐예요?

학기 성적은 중간고사·기말고사(지필고사)와 수행평가를 과목마다 정해진 비율로 합쳐서 정해져요. 점수를 넣으면 그 계산을 대신해 줍니다.

선택학년 · 학기 · 과목 고르기

고르면 그 과목의 비율과 시험 유형(중간고사만 / 기말고사만 / 둘 다)이 자동으로 적용돼요. 1학년 1학기는 평가가 없어요.

기능 1목표 등급 커트라인 계산

이미 받은 점수를 넣으면 목표 등급에 필요한 최소 점수를 알려줘요.
· 기말만 보는 과목: 수행평가 → 필요한 기말고사
· 둘 다 보는 과목: 중간고사 + 수행평가 → 필요한 기말고사
· 중간만 보는 과목: 중간고사 → 필요한 수행평가

기능 2최종 성적 계산

과목에 맞는 칸(중간·기말·수행)에 점수를 모두 넣으면 최종 원점수와 등급이 나와요. 등급은 A 89.5 · B 79.5 · C 69.5 · D 59.5점 이상이에요.
